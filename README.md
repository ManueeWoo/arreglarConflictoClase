# Arreglo de conflicto
### Descripción
Este proyecto trata de arreglar un conflicto en Git, crearemos un proyecto en GitHub y lo clonaremos a nuestra maquina local, implementaremos un código para hacer una practica y a partir de ahí haremos commits, merges, add y push.
### Features
Las funciones principales es hacer una rama a partir del main para probar los conflictor.
